Language Detection — Rule-Based (no ML model)
Arabic regex [؀-ۿ] hit → "ar", conf=0.99
Hindi _HI_WORDS token ratio > 0.12 and hi ≥ tl → "hi", conf=min(0.99, 0.6+ratio)
Tagalog _TL_WORDS token ratio > 0.12 → "tl", conf=min(0.99, 0.6+ratio)
English fallback → "en", conf=0.90
Romanised Hindi defeats off-the-shelf detectors — keyword scoring is more reliable at this data scale
Classifier Stack (first-wins, graceful fallback)
WAFA_CLASSIFIER=finetuned DistilmBERT — two pipeline() calls (issue + signal models)
default (lstm) Keras LSTM — loaded from lstm_listen.keras via lazy singleton
fallback Keyword heuristic — regex + phrase lists, always available, demo never breaks
Models loaded lazily; _lstm_failed / _finetuned_failed flags prevent repeated load attempts
Entity Extraction — Regex + Gazetteers
amounts_aed (AED/DHS regex) dates (phrase list, 4 langs) destinations (country gazetteer) products (banking product gazetteer)
Leaving Confirmed — Multilingual Phrase List
Explicit relocation phrases in EN + AR + HI (romanised) + TL. Any match → leaving_confirmed=True. This single flag overrides all model scores in M2 (floors fused_risk at 0.85) and forces Rule 1 in M3 (dignified goodbye). Human intent outranks all ML.

M2
UNDERSTAND
wafa/m2_understand.py
Behaviour Score
Load customer row from customers.csv by customer_id, run trained sklearn Pipeline:
X = customer[NUMERIC + BOOLEAN + CATEG]
behaviour_score = logreg.predict_proba(X)[0, 1]
# if customer_id not found → behaviour_score = 0.5
# (neutral prior; text carries the assessment)
Text Score Mapping
text_score = {
  "High": 0.90,
  "Medium": 0.55,
  "Low": 0.15
}[churn_signal]
Fusion Formula
W_BEHAVIOUR, W_TEXT = 0.55, 0.45

fused_risk = W_BEHAVIOUR × behaviour_score
           + W_TEXT × text_score

# Override 1: explicit intent outranks model
if leaving_confirmed:
  fused_risk = max(fused_risk, 0.85)

# Override 2: shaky prediction → human triage
needs_human_triage = (
  issue_confidence < 0.50 or
  churn_signal_confidence < 0.50
)
Risk Banding
"Critical" ← fused_risk ≥ 0.75
"High" ← fused_risk ≥ 0.55
"Medium" ← fused_risk ≥ 0.35
"Low" ← otherwise
Per-Feature Explainability Reasons (shown in dashboard)
balance_trend_3m < −0.15 → "balance draining (X% over 3m)"
salary_credit_active == 0 → "salary credits have stopped"
intl_transfer_spike == 1 → "spike in international transfers"
complaints_6m ≥ 3 → "N complaints in 6 months"
branch_visits_trend < −0.4 → "branch engagement falling sharply"
tenure_months ≤ 12 → "new relationship (N months tenure)"
remittance_count_3m ≥ 8 → "N remittances in 3 months"

M3
ACT
wafa/m3_act.py
Decision Rules — Transparent, Numbered, Top-down (first terminal wins)
Rule 0 needs_human_triage → human_triage — route to a human, no draft
Rule 1 leaving_confirmed → dignified_goodbye — thank them, help them leave, NEVER retention pressure
Rule 2 risk_band ∈ {Critical, High} →
2a Fees_Charges + offer(AED 200) ≤ 0.02×CLV → fee_waiver; else downgrade to rm_call
2b Remittance_Transfer + offer(AED 100) ≤ 0.02×CLV → remittance_support; else rm_call
2c Loan_Mortgage → loan_restructure_info (guidance call, no monetary offer)
2d segment ∈ {Premium, Private} → rm_call
2e else → service_fix
Rule 3 issue ∈ {App_Technical, Card_Services} → service_fix
Rule 4 risk_band == "Medium" → proactive_checkin
Rule 5 Low risk, routine query → answer_query
Offer Economics
OFFER_CAP_PCT = 0.02 # never spend >2% of CLV
cap = OFFER_CAP_PCT × clv_estimate_aed
if offer_value > cap:
  action = "rm_call" # downgrade to personal call
LLM Outreach Drafting — Qwen2.5-0.5B-Instruct
Loaded lazily via transformers.pipeline("text-generation", model="Qwen/Qwen2.5-0.5B-Instruct"). Skipped when WAFA_USE_LLM=0. ~30–60 s on CPU per draft.
SYSTEM_PROMPT hard rules (tone constraints, shown in dashboard):
1. Write ENTIRE message in {language} — no mixing
2. NO false urgency, NO pressure, NO "limited time"
3. Mention ONLY the approved offer — never invent amounts
4. dignified_goodbye: thank them, help them leave, do NOT retain
5. Plain language, no marketing clichés
6. Begin "Dear customer" (in language) · end "Falcon Bank Customer Care"

max_new_tokens=220, do_sample=False
Guardrails — Any Violation → Template Fallback
• Urgency blacklist: "act now", "last chance", "limited time", "urgent", "expires", "only today", "final offer"
• Unfilled placeholders: […] or {…} in draft text
• Invented amounts: AED figures present but ≠ approved offer value
• Language mismatch: detect_language(draft) ≠ customer language
• Retention pressure in goodbye: "stay with us", "special offer", "don't leave"
• Draft too short: < 20 words
Template Fallback — 9 Actions × 4 Languages
Curated templates for every action in EN / AR / HI (romanised) / TL. Always available — demo never breaks regardless of LLM or GPU availability.

Ethics Requirements
Dignified goodbye. leaving_confirmed → Rule 1 fires before any retention logic. The customer is thanked and helped to close accounts smoothly, never pressured to stay. Templates in all 4 languages. The expat who leaves well returns — and refers.
No dark patterns. System prompt hard-prohibits urgency language, invented offers, and pressure tactics. Six guardrails validate every LLM draft. Any violation triggers the curated template fallback. Prompt is shown on-demand in dashboard accordion.
Multilingual fairness. All 4 languages have curated templates guaranteeing a response in the customer's language. Per-language accuracy reported honestly in the bake-off — Arabic LSTM collapse on unseen data (10%) is disclosed, not hidden.
Human in the loop. No LLM-drafted message reaches a customer without an explicit Approve click. The Textbox is editable before approval. The audit log records actor, verdict, and the exact final text approved.
Offer economics + fairness. All monetary offers capped at 2% of CLV — bank never over-spends on retention. nationality_region excluded from the churn model; fairness audit confirms risk scores are calibrated across all 5 nationality regions.
